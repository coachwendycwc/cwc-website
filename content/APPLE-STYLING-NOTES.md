# Apple Enterprise Styling Assessment

**Date:** 2025-12-28

## Current State: 60-70% Apple

The site has Apple-inspired foundations but doesn't fully commit to Apple enterprise aesthetic.

---

## What's Apple-like (Current)

- SF Pro Display font stack
- Large typography with tight letter-spacing (-0.025em)
- Generous whitespace (10rem sections on desktop)
- Pill-shaped buttons (border-radius: 9999px)
- Subtle gradients (gray to white)
- Smooth hover transitions (0.3s ease)
- Card animations (translateY on hover)
- Anti-aliased text rendering
- Clean neutral palette

---

## What's Missing for True Apple Enterprise

| Current | Apple Would Do |
|---------|----------------|
| Cyan accent (#3EBCE8) | Pure black/white with minimal accent |
| Colorful gradient text | Single color or subtle gray gradients |
| Multiple brand colors (cyan, pink, yellow, green) | 1-2 colors max, mostly monochrome |
| Standard hero size | Full viewport hero with dramatic scale |
| Rounded 1.5rem cards | Sharper or more subtle rounding |
| Visible borders on cards | Borderless, shadow-based depth |
| Multiple colored service cards | Uniform, monochrome cards |

---

## To Achieve Full Apple Enterprise Styling

### Typography
- Even larger hero text (8-10rem on desktop)
- More dramatic weight contrast (thin body, bold headlines)
- Pure black (#000) for headlines, not neutral-900

### Color
- Reduce to single accent color (cyan or black)
- Remove pink, yellow, green, purple accents
- Use grayscale for most UI elements
- White backgrounds dominate

### Layout
- Full viewport hero sections
- More dramatic negative space
- Sticky scroll effects on key sections
- Full-bleed images

### Components
- Remove colored accent dots from cards
- Borderless cards with subtle shadows only
- Larger, more dramatic CTAs
- Single column focus on key messages

### Animations
- More refined micro-interactions
- Parallax scroll effects
- Fade-in on scroll
- Video backgrounds on hero

## Decision

Keeping current colorful brand palette for now - it better reflects the warmth and energy of the coaching business. Apple aesthetic can be revisited for a more corporate/enterprise version if needed.
