How to Install This Signature

  1. Open this file in a browser
  2. Select the signature content inside the white box (Cmd+A or click and drag)
  3. Copy (Cmd+C / Ctrl+C)
  4. Gmail: Settings → See all settings → General → Signature → Paste
  5. Outlook: Settings → Mail → Compose and reply → Email signature → Paste
  6. Apple Mail: Preferences → Signatures → Create new → Paste
